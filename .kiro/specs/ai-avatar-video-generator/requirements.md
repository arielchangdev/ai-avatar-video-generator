# Requirements Document

## Introduction

AI 虛擬人物影片生成系統：使用者提供聲音樣本、人物外觀（圖片或影片）及講稿文字，系統將生成具有該聲音與外觀的自然人物講解影片和音檔。人物的動作、嘴型及表情應自然且與語音同步。

## Glossary

- **System（系統）**: AI 虛擬人物影片生成系統的整體
- **Voice_Cloner（語音複製器）**: 負責根據聲音樣本複製目標說話者聲音特徵的模組
- **Avatar_Renderer（虛擬人物渲染器）**: 負責根據人物外觀資料生成動態人物影像的模組
- **Lip_Sync_Engine（唇形同步引擎）**: 負責將生成的語音與人物嘴型動作進行同步的模組
- **Script_Processor（講稿處理器）**: 負責解析並處理輸入講稿文字的模組
- **Video_Composer（影片合成器）**: 負責將音訊和影像合併為最終影片輸出的模組
- **Voice_Sample（聲音樣本）**: 使用者提供的目標說話者音訊檔案，用於複製聲音特徵
- **Appearance_Asset（外觀素材）**: 使用者提供的人物圖片或影片，用於建立虛擬人物外觀模型
- **Script（講稿）**: 使用者提供的文字內容，虛擬人物將照此內容說出

## Requirements

### 需求 1：聲音樣本上傳與驗證

**使用者故事：** 身為使用者，我想上傳聲音樣本，以便系統能複製我指定的聲音特徵來生成語音。

#### 驗收條件

1. WHEN 使用者上傳一個聲音樣本檔案，THE System SHALL 接受 WAV、MP3、FLAC 格式、取樣率不低於 16kHz、且檔案大小不超過 50MB 的音訊檔案
2. IF 使用者上傳的聲音樣本時長少於 3 秒，THEN THE System SHALL 拒絕該檔案並顯示錯誤訊息，說明音訊樣本最低時長為 3 秒
3. IF 使用者上傳的聲音樣本時長超過 300 秒，THEN THE System SHALL 拒絕該檔案並顯示錯誤訊息，說明音訊樣本最長時長為 300 秒
4. WHEN 使用者上傳的聲音樣本通過格式、大小、取樣率及時長（3 秒至 300 秒）驗證，THE System SHALL 接受該樣本、開始聲紋分析，並於 2 秒內向使用者顯示處理中的進度指示
5. IF 上傳的檔案格式不在支援清單（WAV、MP3、FLAC）內或檔案損壞無法解碼，THEN THE System SHALL 拒絕該檔案並返回錯誤訊息，列出支援的格式清單與檔案大小上限
6. IF 聲音樣本上傳過程因網路中斷或逾時（超過 120 秒無資料傳輸）而失敗，THEN THE System SHALL 終止上傳、釋放已接收的暫存資料，並顯示錯誤訊息告知使用者上傳失敗及可重新嘗試

### 需求 2：外觀素材上傳與驗證

**使用者故事：** 身為使用者，我想上傳人物外觀的圖片或影片，以便系統能生成具有該外觀的虛擬人物。

#### 驗收條件

1. WHEN 使用者上傳一張人物圖片，THE System SHALL 接受 JPG、PNG、WEBP 格式、解析度至少為 512x512 像素、且檔案大小不超過 20MB 的圖片
2. WHEN 使用者上傳一段人物影片作為外觀素材，THE System SHALL 接受 MP4、MOV 格式、解析度至少為 512x512 像素、時長不超過 60 秒、且檔案大小不超過 200MB 的影片
3. WHEN 外觀素材上傳成功且偵測到多張人臉，THE Avatar_Renderer SHALL 擷取素材中面積最大的單一人臉區域作為外觀來源
4. IF 上傳的外觀素材中偵測不到人臉，THEN THE System SHALL 拒絕該素材並返回錯誤訊息，說明素材需包含至少一張清晰正面人臉
5. IF 上傳的圖片解析度低於 512x512 像素，THEN THE System SHALL 拒絕該檔案並返回錯誤訊息，說明最低解析度要求為 512x512 像素
6. IF 上傳的檔案格式不屬於圖片（JPG、PNG、WEBP）或影片（MP4、MOV）的允許格式，THEN THE System SHALL 拒絕該檔案並返回錯誤訊息，列出允許的檔案格式
7. IF 上傳的圖片檔案大小超過 20MB 或影片檔案大小超過 200MB，THEN THE System SHALL 拒絕該檔案並返回錯誤訊息，說明對應媒體類型的檔案大小上限
8. IF 上傳的影片時長超過 60 秒，THEN THE System SHALL 拒絕該檔案並返回錯誤訊息，說明影片時長上限為 60 秒

### 需求 3：講稿輸入與處理

**使用者故事：** 身為使用者，我想輸入講稿文字，以便虛擬人物能按照講稿內容說話。

#### 驗收條件

1. WHEN 使用者輸入講稿文字，THE Script_Processor SHALL 接受長度介於 1 至 10000 個字元之間的文字內容，且輸入內容須包含至少一個非空白字元
2. WHEN 講稿文字包含多國語言（中文、英文），THE Script_Processor SHALL 依據連續字元區段辨識語言，並於處理結果中標註各區段所屬語言，同時保留原始混合語言之排列順序
3. THE Script_Processor SHALL 將講稿中的連續換行符號（兩個以上的換行字元）識別為段落分隔，並於輸出中保留段落分隔標記，以作為後續語音合成時插入停頓的依據
4. IF 使用者輸入的講稿超過 10000 個字元，THEN THE Script_Processor SHALL 拒絕該輸入並返回錯誤訊息，說明字數上限為 10000 個字元並顯示目前輸入字數，且不清除使用者已輸入的內容
5. IF 講稿文字包含中文與英文以外的字元（如特殊符號、emoji、其他語系文字），THEN THE Script_Processor SHALL 保留該字元於原始位置，並將其標註為未識別語言區段
6. WHEN Script_Processor 接收到有效講稿輸入，THE Script_Processor SHALL 於 3 秒內完成處理並返回處理結果

### 需求 4：語音合成與聲音複製

**使用者故事：** 身為使用者，我想讓系統用我提供的聲音特徵來朗讀講稿，以便生成的語音聽起來像是指定的人在說話。

#### 驗收條件

1. WHEN 聲音樣本分析完成且講稿已處理，THE Voice_Cloner SHALL 使用聲音樣本的音色特徵來合成講稿內容的語音，並於合成完成後輸出完整的音訊檔案
2. THE Voice_Cloner SHALL 生成的語音在音調和音色上與原始聲音樣本的相似度達到說話者辨識模型（Speaker Verification Model）之餘弦相似度 0.75 以上
3. THE Voice_Cloner SHALL 生成語音時，語速維持在每分鐘 120 至 180 個中文字的範圍內，且語句內具有音調高低變化（基頻標準差不為零）
4. WHEN 講稿中包含段落分隔，THE Voice_Cloner SHALL 在段落之間插入 0.5 秒至 1.5 秒的靜音停頓間隔
5. THE Voice_Cloner SHALL 輸出 WAV 格式的音訊檔案，取樣率為 44100Hz 或以上，位元深度為 16-bit 或以上
6. IF 聲音樣本長度不足 3 秒或音訊品質無法辨識有效語音特徵，THEN THE Voice_Cloner SHALL 拒絕合成並回傳錯誤訊息，說明聲音樣本不符合最低需求
7. IF 語音合成過程中發生失敗，THEN THE Voice_Cloner SHALL 停止處理、不輸出不完整的音訊檔案，並回傳錯誤訊息指出合成失敗原因

### 需求 5：人物影像生成與唇形同步

**使用者故事：** 身為使用者，我想讓生成的虛擬人物嘴型和表情與語音同步，以便影片看起來自然真實。

#### 驗收條件

1. WHEN 語音合成完成，THE Lip_Sync_Engine SHALL 分析語音的音素時序，以至少 24 fps 的幀率生成對應的嘴型動畫序列
2. THE Avatar_Renderer SHALL 根據外觀素材生成人物影像，確保生成的臉部特徵與原始素材的相似度分數達到 0.90 以上（基於臉部特徵向量比對）
3. THE Lip_Sync_Engine SHALL 確保嘴型動作與語音之間的時間偏差不超過 80 毫秒
4. THE Avatar_Renderer SHALL 為人物加入微表情變化，包含每分鐘 15 至 20 次的眨眼頻率，以及幅度在 ±2 度以內的微幅頭部擺動
5. WHILE 語音中存在超過 500 毫秒的靜音停頓，THE Avatar_Renderer SHALL 生成待機姿態，包含可辨識的呼吸動畫循環與隨機間隔的眨眼動作
6. IF 語音合成失敗或音素時序資料無法產出，THEN THE Lip_Sync_Engine SHALL 停止動畫生成流程，並回傳錯誤訊息指出失敗原因
7. IF 外觀素材不可用或格式不符合支援規格，THEN THE Avatar_Renderer SHALL 中止人物影像生成，並回傳錯誤訊息指出素材問題類型

### 需求 6：影片合成與輸出

**使用者故事：** 身為使用者，我想取得最終合成的影片和音檔，以便用於簡報、教學或其他用途。

#### 驗收條件

1. WHEN 語音和人物影像均已生成完成，THE Video_Composer SHALL 將音訊與影像合併為 MP4 格式影片
2. THE Video_Composer SHALL 輸出的影片解析度至少為 720p（1280x720）
3. THE Video_Composer SHALL 輸出的影片幀率為 25fps 或以上
4. WHEN 影片合成完成，THE System SHALL 同時提供獨立的音訊檔案（MP3 格式，位元率至少 128kbps）供使用者單獨下載
5. WHEN 影片合成完成，THE System SHALL 提供影片預覽功能，使用者可播放完整影片並確認音畫同步後再下載
6. THE Video_Composer SHALL 確保最終影片中音訊與影像的時間偏移不超過 ±40 毫秒
7. IF 影片合成過程中發生錯誤，THEN THE System SHALL 顯示錯誤訊息指出失敗原因，並保留已生成的語音與影像素材供使用者重新嘗試合成
8. IF 影片合成時間超過影片時長的 3 倍且超過 180 秒，THEN THE System SHALL 終止合成作業並通知使用者合成逾時，允許使用者重新觸發合成

### 需求 7：處理進度與狀態回報

**使用者故事：** 身為使用者，我想在生成過程中得知處理進度，以便了解還需等待多久。

#### 驗收條件

1. WHILE 系統正在處理生成任務，THE System SHALL 每 3 秒內至少更新一次目前的處理階段名稱和整體進度百分比（0% 至 100%）
2. THE System SHALL 將處理流程依序分為以下 5 個階段回報：聲紋分析、語音合成、人臉建模、唇形同步、影片合成，且每個階段開始時進度百分比須嚴格遞增
3. IF 處理過程中發生錯誤，THEN THE System SHALL 顯示錯誤訊息（包含失敗的階段名稱與錯誤原因類別），並提供重試選項，重試時從失敗的階段重新開始處理
4. WHEN 生成任務完成，THE System SHALL 通知使用者並提供下載連結，該連結自生成起至少 24 小時內保持有效
5. IF 使用者在處理過程中離開頁面後重新返回，THEN THE System SHALL 恢復顯示該任務當前的處理階段與進度百分比

### 需求 8：輸入素材組合驗證

**使用者故事：** 身為使用者，我想在提交生成任務前確認所有必要素材已備齊，以免生成中途失敗浪費時間。

#### 驗收條件

1. WHEN 使用者提交生成任務，THE System SHALL 驗證聲音樣本、外觀素材和講稿三項必要輸入均已上傳且檔案大小大於 0 bytes
2. IF 任一必要輸入未上傳或檔案大小為 0 bytes，THEN THE System SHALL 逐項列出每個缺少或無效素材的名稱，並阻止任務提交
3. IF 聲音樣本時長少於 3 秒或超過 300 秒，THEN THE System SHALL 顯示錯誤訊息指出聲音樣本時長超出允許範圍（3–300 秒），並阻止任務提交
4. IF 講稿字數少於 1 字或超過 10,000 字，THEN THE System SHALL 顯示錯誤訊息指出講稿字數超出允許範圍（1–10,000 字），並阻止任務提交
5. WHEN 所有必要輸入均通過驗證，THE System SHALL 顯示素材摘要，包含聲音樣本時長（秒）、外觀素材類型名稱、及講稿字數，並要求使用者按下確認按鈕後方可開始生成任務
